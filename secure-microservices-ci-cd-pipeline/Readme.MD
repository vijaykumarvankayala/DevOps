This is a template for a secure, automated CI/CD pipeline built with Jenkins on AWS EKS for deploying microservices. The pipeline integrates DevSecOps practices including static code analysis, container scanning, compliance benchmarking, GitOps deployment, and observability via Prometheus and Grafana. I am open to suggestions on how to make this configuration run smoother or more securely. This was fun to work on and had some troubleshooting along the way.
